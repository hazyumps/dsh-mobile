What moves where

TodayProposedWhy
Drawer: workspace tree with sessions nested Gone from the drawer. Projects are a section on Home; a project opens full-screen (4). The tree needed the screen it did not have — expand state was lost every time, and reaching a session took four steps behind a modal.
Drawer: New session row + its explanatory caption Gone. The floating composer (1) and the project screen's New session (4). The drawer was a third way to do the same thing, and the caption existed to explain a button that should not need one.
Drawer: Harness fold (Usage, Plugins, Scheduled tasks) + Settings row The whole drawer: Host, Harness (5 rows), Host (3 rows), About (2). Rare, wide, administrative — exactly what a slide-over is for. Settings stops being a separate screen and becomes these rows.
Home: whale heading, host row, workspace card, mode controls, composer, "Continue a session" Recents, then Projects. Composer floats. Workspace/preset/model move into the new-session screen (3). Six stacked sections before the first session left no room for the sessions. The controls that only matter when creating now live where creating happens.
Home: host/status row across the top Host and state live in the drawer's host card and the new-session Host row. Home shows a banner only when the state is not connected. “Connected — Mac.fernlabs.net” was the first thing on the page every single time. The healthy case needs no space; the broken one does.
Home: recent sessions from the selected workspace only Recents across every project, newest first, with live state. "Return to work" does not care which project the work was in. The project is chosen when you start something, not when you resume it.
Session browser (a screen reachable two taps deep) The project screen itself (4), with date groups and a filter. Same idea, one less step: the project row on Home goes straight there.
Five calls I need from you — everything else I can decide.
  1. The whale / “Into the Unknown” heading. Proposal: show it only when Home has nothing to list — it introduces the product instead of pushing your work below the fold. That is a deviation from UX spec “Home” item 4, so it is yours to call. Alternative: keep it, compact, above Recents.
  2. Four recents, or more? Four fills the first screen at this density. A “See all” link (drawn) covers the rest.
  3. Pinned. Not drawn. Codex has it; we currently have no pin concept. It slots above Recents if you want it, and it would need a host-side or phone-side store — say the word and I will price it.
  4. New session: screen or sheet? Drawn as a pushed screen with a back chevron, matching your second screenshot. A sheet is also possible — faster to dismiss, but the preset and model pickers nest badly.
  5. Host in the toolbar? I kept the DeepSeek Harness wordmark centred, per the UX spec, and put host plus connection in the drawer's host card and the new-session Host row. If you would rather see which Mac you are on from Home, the toolbar centre becomes the host name with a chevron — that is your reference screenshot's own arrangement.
